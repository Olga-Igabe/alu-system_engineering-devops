\# Web server



Bash scripts and files for setting up and configuring an Nginx web server.



\- `0-transfer\_file` - transfers a file to a server's home directory using scp

\- `1-install\_nginx\_web\_server` - installs Nginx with a page containing Holberton School

\- `2-setup\_a\_domain\_name` - the domain name pointing to the web-01 server

\- `3-redirection` - configures /redirect\_me as a 301 Moved Permanently redirect

\- `4-not\_found\_page\_404` - configures a custom 404 page containing Ceci n'est pas une page

\- `5-design\_a\_beautiful\_404\_page.html` - a custom designed 404 page
